Hello, I would like to present a demo version of my game, "Sector." The game is still a work in progress, but it already features 30 completed levels, plus a final 31st level—a boss battle. The demo version includes 3 playable levels. The game runs on ECS, AGA, RTG, MiniGL, and OGLES2. Ideally, you should have a 040 processor and 16MB of Fast RAM. It is also possible to run it on a 020 processor with 8MB of RAM, though, at the moment, it takes longer to load than it should
